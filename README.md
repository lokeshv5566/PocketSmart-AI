# PocketSmart AI — Complete Gemini 2.5 Flash Source Code

PocketSmart AI is a FastAPI + Jinja2 web application for budget-aware recommendations in three areas:

1. **Home Interior Planner** — room, style, items and budget.
2. **Party/Event Planner** — guests, event type, venue, city, preferences and budget.
3. **Jewelry Planner** — occasion, style, metal, budget and optional outfit image.

The AI integration uses **Gemini 2.5 Flash** through the Gemini REST API. If the API key is missing or the AI request fails, the app uses local fallback recommendations so the application can still be demonstrated.

## Windows setup in VS Code

### Option A — easiest

1. Open this folder in VS Code.
2. Open **Terminal → New Terminal**.
3. Run:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, run this once in the same terminal:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### Option B — Windows batch files

Double-click `setup_windows.bat` once. Then edit `.env` and run `run.bat`.

## Configure Gemini

Copy `.env.example` to `.env` and set:

```env
GEMINI_API_KEY=YOUR_KEY_HERE
GEMINI_MODEL=gemini-2.5-flash
```

Do not commit your real API key to GitHub.

## Run

```powershell
python -m uvicorn app.main:app --reload
```

Open:

- http://127.0.0.1:8000
- http://127.0.0.1:8000/docs
- http://127.0.0.1:8000/health

## Test

```powershell
pytest -q
```

## Notes

- SQLite is used for local development.
- Passwords are hashed with PBKDF2-HMAC-SHA256.
- Authentication uses an HTTP-only JWT cookie.
- Marketplace links are search links, not live inventory APIs.
- Prices generated by the application are estimates unless a real marketplace API is connected.
- The optional jewelry image is sent to Gemini only when a Gemini API key is configured and the user uploads an image.
